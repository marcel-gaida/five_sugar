# five_sugar

A collection of small apps, browser extensions, scripts, and notebooks for solving practical problems quickly.

## Repository layout

The repository is organized by project type so it is easier to browse and maintain.

```text
five_sugar/
├── apps/          # Browser extensions and app-style projects
├── scripts/       # Standalone utility scripts
├── notebooks/     # Jupyter notebooks and experiments
└── archive/       # Older or superseded projects and releases
```

## What is inside

### Apps
Projects in `apps/` are self-contained tools and extensions, including current browser-extension style projects and packaged releases that still belong to those apps.

### Scripts
Projects in `scripts/` are focused utilities for one-off or repeatable tasks such as CSV cleanup, Excel cleanup, mouse automation, and map generation.

### Notebooks
Projects in `notebooks/` contain exploratory work, research, scraping experiments, and data analysis notebooks.

### Archive
Projects in `archive/` contain older versions, legacy work, or projects that are no longer the active version.

## Getting started

1. Clone the repository.
2. Open the folder that matches the type of project you want to explore.
3. Read the local files for that project, such as `README.md`, notebook cells, or source files.

```bash
git clone https://github.com/marcel-gaida/five_sugar.git
cd five_sugar
```
