# Changelog

## [1.0.0] - 2026-06-03
### Initial Release
- Local folder browsing via File System Access API
- PDF and image thumbnail preview generation
- Tagging system with colour-coded chips and autocomplete
- 1–5 star rating system
- Bookmark system with page/scroll position saving
- In-extension PDF and image viewer with zoom controls
- Search across file names, tags, and folder paths
- Filter by file type and rating
- Natural sort (alphabetical with correct number ordering)
- Light and dark theme toggle
- Export/import metadata as JSON
- Reconnect to previously selected folder on relaunch
