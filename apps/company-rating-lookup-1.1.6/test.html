Company Rating Lookup Playground

Use this page to test the Chrome Extension's right-click context menu and floating visual ratings card.

Instructions for testing:
  1. Highlight a company name in the list below (e.g. select Google).
  2. Right-click the selected text to trigger the custom context menu.
  3. Select "Look up company ratings".
  4. Observe the floating dark rating card showing ratings and click-through buttons.
  5. Confirm that a visual inline badge (e.g., ★ G: 4.5 · M: 4.6) is injected right next to the company name text.
