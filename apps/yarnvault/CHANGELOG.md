# Changelog

## [1.0.2] - 2026-07-19
### Added
- Added a full screen toggle button for open pattern files in the viewer.
- The row counter panel now slides in smoothly from the left side and adjusts the viewer width dynamically when in full screen mode.
- Created `YarnVault_Release 1.0.2.zip` containing the updated extension files.

## [1.0.1] - 2026-06-06
### Added
- Documented the Row Counter feature in the README.md.
- Created `YarnVault_Release.zip` containing only the files needed to run the extension for easier installation.

### Changed
- Updated README.md installation steps to link to the new release zip file.
- Updated README.md to accurately document the available app themes (Light Mode, Dark Mode, Solarized Dark).
- Added a technical structure breakdown to the README.md.
- Changed the project license to Creative Commons Attribution-NonCommercial 4.0 International (CC BY-NC 4.0).

## [1.0.0] - 2026-06-03
### Initial Release
- Local folder browsing via File System Access API
- PDF and image thumbnail preview generation
- Tagging system with colour-coded chips and autocomplete
- 1–5 star rating system
- Bookmark system with page/scroll position saving
- In-extension PDF and image viewer with zoom controls
- Search across file names, tags, and folder paths
- Filter by file type and rating
- Natural sort (alphabetical with correct number ordering)
- Light and dark theme toggle
- Export/import metadata as JSON
- Reconnect to previously selected folder on relaunch
